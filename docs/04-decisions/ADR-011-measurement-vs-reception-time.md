# ADR-011 — Measurement Time and Reception Time Are Separate

- **Status:** Accepted
- **Date:** 2026-09-20
- **Decision:** Telemetry records contain both physical observation time and backend reception time.

## Context

A device may observe a value at one time and the backend may receive it later. Network delay, intermittent connectivity, buffering, and out-of-order delivery make these moments distinct.

## Decision

Use:

```text
measuredAt = when the physical observation occurred
receivedAt = when the backend received the observation
```

Both use `Instant` and UTC/ISO-8601 semantics.

`receivedAt` is generated by the backend.

The system must not enforce `measuredAt <= receivedAt` as an absolute invariant because device clocks may be inaccurate.

## Consequences

- Telemetry latency can be measured.
- Out-of-order observations can be handled.
- Historical ordering can use physical observation time.
- Device clock quality remains a separate concern.
